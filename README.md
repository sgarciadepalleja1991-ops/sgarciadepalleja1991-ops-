## 🚀 Proyectos destacados

### 🚨 Respuesta en vivo a incidentes: servidor Ubuntu comprometido
*Proyecto final · Bootcamp de Ciberseguridad 4Geeks Academy × UTEC · NIST CSF 2.0 y SP 800-61 Rev. 3*

- Ejecuté un **Live Incident Response** sobre un servidor Ubuntu 20.04 comprometido **sin interrumpir el servicio**.
- Encontré la **persistencia mediante cron (root) cada 15 minutos**, reconstruí la cronología del ataque y descarté como vector **15 intentos de fuerza bruta por SSH**.
- Mapeé las técnicas a **MITRE ATT&CK** (T1566, T1204.002, T1041).
- Audité **Wazuh SIEM/EDR, UFW, SSH y vsftpd**: clasifiqué **8 vulnerabilidades** por severidad y descarté **12 vectores** por verificación negativa.
- Preservé la **cadena de custodia con SHA-256** y documenté todo en un **informe técnico de 41 páginas**, junto con un plan de contención, erradicación, recuperación y hardening, y un informe ejecutivo.

### 🔐 Sistema de gestión de traslados: INAU Paysandú
*Cloudflare Pages Functions · D1 · en producción*

- Diseñé y desplegué en producción el sistema de gestión de traslados de la oficina.
- **Autenticación con PBKDF2**, sesiones revocables, bloqueo por intentos fallidos y **protección contra la enumeración de usuarios**.
- Encabezados de seguridad **CSP y HSTS**.
- **Control de acceso por rol en el servidor**, aislamiento de datos por organización y **privacidad desde el diseño**: el sistema no guarda datos que identifiquen a menores.

### 📊 Sistema de gestión contable multiempresa
*Cloudflare Workers · D1 · desarrollo freelance para Estudio Ferreira Muzzio · en producción*

- Diseñé y desplegué la **arquitectura backend multiempresa** sobre Cloudflare Workers y la base relacional D1.
- Implementé **controles de seguridad en la API** para flujos contables, presupuestos y control de obligaciones fiscales.
- Integré y aseguré endpoints con la **API de Kimi K2.5**, mediante microservicios dedicados, para clasificar datos de forma automática.
